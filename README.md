# Python និង Django៖ រៀនពីមូលដ្ឋានដល់កម្រិតខ្ពស់

វគ្គសិក្សាជាភាសាខ្មែរ ដែលរៀបតាមលំដាប់ **Python ជាមុន** រួចបន្តទៅ **Django Framework**។ មេរៀននីមួយៗនឹងពន្យល់គោលគំនិត, ហេតុផលប្រើ, syntax, code ឧទាហរណ៍, អនុវត្ត, លំហាត់ និងចម្លើយពិនិត្យខ្លួនឯង។

## ផែនការរៀន

### ដំណាក់កាលទី ១៖ Python
ចាប់ពី installation, syntax និង data types ទៅ functions, OOP, generators, decorators, typing, testing, packaging, concurrency, performance និង security។ រៀនមេរៀន Python ជាលំដាប់ មុនចូល Django ព្រោះ Django ប្រើ Python សម្រាប់ models, views, forms និង tests។

- [ផែនទី និងមេរៀន Python](python/README.md)
- **កំណែគោល**៖ Python 3.14; ប្រើឯកសារ Python 3.14 និងពិនិត្យ compatibility របស់ third-party packages មុនប្រើ។

### ដំណាក់កាលទី ២៖ Django Framework
ក្រោយ Python, រៀន Django 6.0៖ project/app, request-response, URLs/views/templates, models/ORM, forms, authentication, testing, APIs, security និង deployment។

- [ផែនទី និងមេរៀន Django](django/README.md)
- **កំណែគោល**៖ Django 6.0 ជាមួយ Python 3.12–3.14 ដែលគាំទ្រតាមឯកសារផ្លូវការ។

## គោលការណ៍អនុវត្ត

- ប្រើ virtual environment មួយសម្រាប់ project នីមួយៗ។
- សរសេរកូដហើយរត់វាដោយខ្លួនឯង; កុំចម្លងដោយមិនយល់។
- បំបែក project ជំហានតូចៗ ហើយសរសេរ README ពន្យល់របៀបរត់។
- កុំដាក់ password, API key, secret key ឬទិន្នន័យអ្នកប្រើក្នុង GitHub។
- Django development server ប្រើសម្រាប់សាកល្បងក្នុង local environment; production ត្រូវប្រើ deployment setup ត្រឹមត្រូវ។
- អនុវត្ត security labs តែលើ project និង environment ដែលអ្នកគ្រប់គ្រង។

## គម្រោងចុងវគ្គ

- Python: CLI task manager, file organizer, API client និង package ដែលមាន tests។
- Django: blog/content system រួចបន្តជា project មាន login, permissions, forms, database, tests និង deployment checklist។
